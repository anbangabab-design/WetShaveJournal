# 湿剃日记（WetShaveJournal）v1.1.0 完整修改说明

> **文档用途**：汇总 `v1.0.0` 实机测试反馈、UI 视觉精简与 Bug 修复、器材库结构与官网统一命名规范、新增「随机抽签」模块，以及后续面向 Damn Fine Shave（DFS）推广的多语言远期规划。

## 0. 项目现状与交接基础

* **应用标识**：`com.personal.wetshavejournal`（macOS 14+ 原生 SwiftUI + Swift Charts，零第三方依赖）
* **本地数据目录**：`~/Library/Application Support/WetShaveJournal/`
  * 核心数据：`journal.json`（保留全部历史 SOTD `entries`，兼容 `overrides` / `pending` / `history`）
  * 应用图标：已定稿 Apple 官方极简纯英文 `SOTD` 石墨钛灰图标（`AppIcon.icns`）
  * 编译注意：请直接使用项目根目录下的 `bash build.sh` 编译打包（已指定 `-sdk /Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk` 并将中间产物输出至 `/tmp`，避免在 Google Drive 同步目录生成 `.build/` 碎文件）。
* **同步与识别策略**：
  * 仅保留 Apple 备忘录单向同步（`read-notes.js`），暂不做 App 反向写回备忘录；
  * 联网自动识别保持免 API Key 方案（参考 Badger & Blade、Damn Fine Shave、Reddit 及品牌官网），暂不接入大模型 API。

## 一、UI 视觉精简与已知 Bug 修复

1. **空数据布局错位修复**
   * **问题**：日记为 `0` 篇时，右侧分栏上半部分大片空白，搜索栏和空状态提示被挤到窗口底部并截断。
   * **方案**：日记页 `HSplitView` 左右分栏强制顶对齐并撑满高度；空状态视图居中展示；**数据统计页**在 `0` 篇日记时也提供干净的空态引导，避免空白图表或除零异常。

2. **侧边栏底部深浅色切换按钮点击热区修复**
   * **问题**：「跟随系统 / 浅色 / 深色」三个图标按钮点击面积过小，只有点到正中间图标才响应。
   * **方案**：为按钮增加 `minHeight: 30` 与 `.frame(maxWidth: .infinity).contentShape(Rectangle())`，整块按钮背景均可响应点击。

3. **「外观与设置」页卡片等宽对齐**
   * **问题**：三个设置区块卡片按内容收缩，右侧宽度参差不齐。
   * **方案**：所有设置卡片统一 `.frame(maxWidth: .infinity, alignment: .leading)`，外层约束统一最大宽度。

4. **新建记录「刮剃步骤」选中跳动修复**
   * **问题**：选中「顺刮 / 横刮 / 逆刮 / 补刀」后，若为可调刀，下方弹出档位框，因 `HStack` 居中对齐导致选中按钮向上跳动、边缘发紧。
   * **方案**：改为 `HStack(alignment: .top, spacing: 10)` 顶部对齐，步骤按钮固定高度与宽裕热区，档位输入框固定展示在对应按钮正下方，彻底消除跳动。

5. **日记列表快捷操作补全**
   * 左侧日记卡片支持**双击直接打开编辑窗口**；
   * 增加 `.contextMenu` **右键菜单**（快捷「编辑」/「删除」，删除保留确认提示）。

6. **空字段残留孤立图标修复**
   * 当某篇日记未填写刀片或剃须皂时，列表卡片底部隐藏对应的孤立图标与分隔圆点 `·`。

7. **整体字号放大与 Apple 原生极简视觉重构**
   * 整体字号上调 1–2pt，增大筛选芯片与点选控件的可点击尺寸；
   * **大幅收敛配色**：主界面回归 Apple 原生黑白灰 + 单一克制强调色，普通属性小框框统一采用浅灰中性胶囊，减少视觉噪点，仅在关键状态和品牌徽章处保留适度点缀。

8. **数据统计页防跳版全面重构**
   * **问题**：多处固定宽度 `HStack` 与硬编码 5 列网格导致窗口缩放时卡片跳版、高度不齐、图例或文字溢出。
   * **方案**：KPI 与图表区全面改为自适应网格（`LazyVGrid`），同行卡片强制等高对齐，热力图自适应宽度，长名称单行截断并支持 hover 显示全称。

## 二、日记详情与新建记录流程优化

1. **「剃须碗」移入装备栏，「起泡方式」回归纯粹**
   * 在日记详情「本日装备」与新建/编辑表单「装备搭配」中增加独立的**剃须碗**装备栏；
   * 流程里的「起泡方式」精简为纯 **`碗起` / `脸起` / `手起`** 三项（向后兼容解析历史记录中的 `XX碗起`）。
2. **日记详情页移除「原始过程记录」**
   * 去掉详情页底部的「原始过程记录：xxx」冗余行；仅当存在额外备注（如「有血点」）时单独显示备注。
3. **巩固既有流程与交互**
   * 取皂方式仅保留 **`挖取` / `刷取` / `涂抹`**，保留**是否热敷**开关；
   * 刀片栏保留自动使用次数累计与**换新刀片（重置为 1st）**按钮；
   * 器材输入栏保留「实时联想搜索框 + 下拉菜单 + 一键新建」，优化联想框点击焦点稳定性。

## 三、器材库全面升级与官网统一命名规范

1. **官网统一命名规则 + 固定属性剥离**
   * 品牌与型号名称尽量对齐**品牌官网正规命名**；
   * 固定属性（如剃须刀的 `SS / Ti / Cu / Brass`、`OC / SB / DC`、刀隙数字；剃须刷的 `Fan / Bulb`、`26mm / 28mm`、`2-Band / 3-Band`、`猪鬃 / 满洲 / 漂尖` 等）从显示名称中剥离，统一以卡片下方的简洁小框框展示：
     * 示例：**Blutt** `BR-1` → `[DE]` `[SB]` `[0.99]` `[不锈钢]`
     * 示例：**RV** `Custom` → `[Shavemac 毛结]` `[獾毛]` `[无漂]` `[二段]` `[26mm]` `[Fan]`
   * 同一型号但材质/刀隙/毛型不同的单品保持独立条目，不误合并。

2. **品牌 Logo 显示**
   * 在每个器材卡片与「按品牌」分组标题中增加**品牌 Logo 圆形徽章**；
   * 常见品牌自动从官网拉取图标并本地缓存；无官方 Logo 的品牌或「仿刀」采用 **iOS 通讯录风格的首字母 / 中文首字圆形徽章**兜底。

3. **剃须刀分类与属性规范**
   * **刀型更正与细分**：「剃刃」更正为**「替刃」**；完整刀型包括 `Double Edge (DE)`、`Single Edge (AC)`、`Single Edge (GEM)`、`Single Edge (Injector)`、`Single Edge (半DE)`、`盒刀`、`Twin Blade`、`直剃`、`替刃`、`其他`（像「树皮 SE1」这类半 DE 单刃刀归为 `SE · 半DE`，自动匹配 DE 刀片）；
   * **`Slant` 独立化**：斜头刀刀型统一归入 `DE`，底板形制精简为纯 **`SB` / `OC` / `DC`**，并像「可调刀」一样单独增加 **`Slant`** 布尔属性与筛选按钮；
   * **材质统一简化**：不再细分 316L / 304 / 303 等牌号，统一为 `不锈钢`、`钛合金`、`黄铜`、`红铜`、`青铜`、`磷青铜`、`铝合金`、`锌合金` 等；
   * **刀隙 / 版本规格**：支持数字（如 `0.99`）或手动文字（如 `Standard`、`Lite`），无参数刀（如天际线）留空且在卡片中完全隐藏不占空间；
   * **仿刀**：统一将品牌归类为 **`仿刀`**。

4. **刀片分类与状态精简**
   * 刀片增加类型分类：**`DE` / `AC` / `GEM` / `Injector` / `盒刀头` / `其他`**；
   * 刀片状态单独精简为 **`有` / `无`**。

5. **全器材状态精简**
   * 统一去掉 **`闲置`** 和 **`空瓶`**；
   * 刀片保留 **`有 / 无`**，其余所有器材仅保留 **`在用 / 借用 / 已出`**。

6. **剃须刷结构升级（手柄品牌 vs 毛结品牌）**
   * 拆分为**手柄品牌**（主品牌 `brand`）与可选的**毛结品牌**（`knotBrand`，混搭刷填写，原厂刷留空），并增加可选**毛型**（`Fan` / `Bulb`）与结径（如 `26mm`）；
   * 历史数据明确拆分：`Shavemac` 原厂柄 `2-Band 26mm Bulb` 与 `RV` 手柄 + `Shavemac` 毛结 `2-Band 26mm Fan`，其余混搭刷（如 `C&H × FS`、`AKA × FS`、`S.ghost × FS`）同理归类。

7. **器材库合并、拆分、清除筛选与导出**
   * **一键清除筛选**：器材库与日记筛选栏激活任意条件时自动显示「清除筛选」按钮；
   * **合并**：支持在器材编辑页将当前器材一键合并至另一个目标器材；
   * **拆分**：支持查看已合并的原始写法清单，并将任意原始写法一键拆分为独立新器材；
   * **不确定装备**：凡无法确认官网参数/材质/刷毛的装备，一律标为 **`待确认`**，不强行猜测；
   * **内置导出**：设置页增加一键「导出装备资料库（CSV）」按钮。

## 四、新增独立模块：「随机抽签 / 随机搭配」

* 侧边栏新增独立模块「随机抽签」；
* 支持**一次抽全套**，也支持**单独抽某一个品类**或**自由勾选参与抽签的品类**，支持单件锁定后重摇其余项；
* **严格排除不在手上的装备**：非刀片品类仅抽取状态为 **`在用`** 的器材，刀片仅抽取状态为 **`有`** 的库存刀片；
* **刀型与刀片自动匹配**：抽中剃须刀时自动按刀型过滤对应类型刀片（`DE / SE·半DE / Twin Blade → DE`；`SE·AC / 替刃 → AC`；`SE·GEM → GEM`；`SE·Injector → Injector`；`盒刀 → 盒刀头`）；
* 抽完支持一键**「用这套记一次 SOTD」**直接预填进入新建日记表单。
